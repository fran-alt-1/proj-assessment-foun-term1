Real world uses of linux

Business

  • Servers: Companies can use linux for any reason as a server to host various internal company thing
  • Automation: Companies can use linux to automate various menial tasks
  • Tests: Companies can use linux to run tests for git commits
  • Hosting: Companies can host anything from dns servers to internal employee management systems
  • Devops: Companies can host any devops tools to smoothen workflow internally

Daily Life

  • Daily Driver: Individuals can use linux as a personal operating system for daily use
  • Home lab: Individuals can use linux to host their own personal services such as cloud storage, network adblock, email servers and etc
  • Automation: Individuals may use linux to automate various tasks in their house such as turning off the ac at certain times

Education

  • Students can learn computer literacy with exposure to increasingly difficult linux distros
  • Bare bones laptops have distributed previously in africa with linux installed to teach kids about linux
Healthcare
  • Linux can be used as a stable system to keep systems online through extreme situations
  • Secure Linux kernels can be used to keep patient info more secure and confidential
