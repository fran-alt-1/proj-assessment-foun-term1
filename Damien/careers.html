Career options with linux

System Administrator

Responsibilities

  1. Install Linux systems
  2. Maintain Linux systems
  3. Configure Linux systems
  4. Ensure Stability of servers and work stations
  5. Ensure Security of servers and work stations

Linux Developer

Responsibilities

  1. Develop scripts for linux environments
  2. Develop applications for linux
  3. Develop tools for linux
  4. May work with system level programming
  5. Contribute to OSS projects

Linux Security Specialist

Responsibilities

  1. Secure Linux systems from data breachers malware and hackers
  2. Implement security policies
  3. Conduct vulnerability assessments
  4. Respond the security incidents
