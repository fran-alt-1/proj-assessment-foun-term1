About The Linux Kernel

What is a kernel

A Kernel is a computer program that is the core of an operating system. The kernel always has complete control over the whole system. It is responsible for preventing conflicts between processes, and it is always in memory. A kernel also controls all hardware resources such as I/O, memory, cryptography and etc via drivers, it optimizes the use of common resources, such as cache, file systems CPU and network sockets. On Almost all systems, the kernel is one of the first programs loaded on the startup. It usually handles the rest of the startup after it such as memory, peripherals and input and output devices

Features of the linux kernel

  • Process scheduler
  • Memory management unit
  • Virtual file system
  • Networking Subsystem
  • Inter-Process Communications Unit

Workplace applications of linux

  • Automating
  • Email Hosting
  • Website Hosting
