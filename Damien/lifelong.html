Lifelong learning with daily driving linux

How using linux as a daily os might teach you

Using linux as a daily os can be beneficial to both developers and regular users. For developers this can be significantly helpful as using linux as a daily driver can teach you about the file system and structure, package managers, and how to fix various issues on linux, all of these skills will help when creating docker containers, maintaining servers and fixing emergency outages. For regular users it can allow you to reach new levels of computer fluency

Things you may pick up

  • Bug fixing skills
  • Unix fs literacy
  • Package manager knowledge
  • User and group permissions understanding
  • Containerization skills
