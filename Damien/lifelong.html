Lifelong learning with daily driving linux

How using linux as a daily os might teach you

Using linux as a daily os can be beneficial to both developers and regular users. For developers this can be significantly helpful as using linux as a daily driver can teach you about the file system and structure, package managers, and how to fix various issues on linux, all of these skills will help when creating docker containers, maintaining servers and fixing emergency outages. For regular users it can allow you to reach new levels of computer fluency

Things you may pick up

  • Bug fixing skills
  • Unix fs literacy
  • Package manager knowledge
  • User and group permissions understanding
  • Containerization skills

Ways to learn

  • Trying various distros
    • What can be learned
      1. How to use various distro
      2. Understanding package managers
      3. Knowing what breaks a system
    • Why is this resource useful
      1. Its easy to start
      2. Its not intimidating
    • How can it support future learning
      1. Diverse exposure to various distro is a good foundation
  • Contributing to community package repositories
    • What can be learned
      1. How linux binaries work
      2. How building and compiling work on linux
      3. Automated install scripts
    • Why is this resource useful
      1. Exposure to how package managers work
      2. Existing coding skills can be used
    • How can it support future learning
      1. Learning a few core systems such as linux binaries, automation, and package managers help everywhere in linux
  • Making various LXC's
    • What can be learned
      1. Variables and arguments that complete a linux system
      2. Closer familiarity to what breaks a system and how to keep it secure
    • Why is this resource useful
      1. There is nearly zero risk in damaging personal system with this
      2. This can be done on any system
    • How can it support future learning
      1. Understanding how to create lxc's can help when developing linux systems
  • Making / Contributing to a linux distro
    • What can be learned
      1. Reading IPC calls
      2. Inner working of distros
      3. Inner working of package managers
    • Why is this resource useful
      1. It allows you to perfectly understand how a certain distro works
    • How can it support future learning
      1. Knowing how a distro works to its internal workings of a distro allows is very useful
  • Contributing to the linux kernel
    • What can be learned
      1. Learning all the system calls
      2. Understanding How linux interacts with the hardware
    • Why is this resource useful
      1. Technical understand of the linux kernel allows you to create anything os related
    • How can it support future learning
      1. You could create your own kernel and learn from that
